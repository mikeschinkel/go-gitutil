NewRepo(dir, RepoArgs) constructs without I/O; (*Repo).Open(ctx, OpenArgs) reads state (replacing OpenRepo, removed); Init and Clone are methods on a constructed Repo; package-level Open, Init and Clone construct and delegate so the implementation lives once. Every other method guards against an unopened Repo. Rationale (Mike, E-2548): a NewRepo() always yields a Repo value, which matters for testing and other uses; Repo{} is constructible regardless, so package-level-only constructors never protected against an uninitialized value. Repo also carries an optional dt.StdIO so one type serves both buffered and streaming callers; Streamer is removed. Open rather than Initialize because Init and Initialize on one type is a trap and callers look for Open.
