Decided by Mike on 2026-11-14 while planning go-goutil's extraction (E-2608, Q2). goutil's FindNestedModules becomes a filesystem walk that runs no git, so it reports a nested module whose directory git ignores. For Add with Exclude that is harmless; for gomion's module graph a caller may want git's view. Mike asked that filtering be performant: one process for all paths, not one per directory. `git check-ignore --stdin -z` answers for every path on stdin in a single run. go-gitutil has IgnoredFiles (an `ls-files -i` listing of the whole tree) but no check against a given list of paths.
