go-gitutil holds git helpers extracted from gomion and has never been tagged. Its go.mod requires go-diffutils at the placeholder v0.0.0 and resolves it, go-dt and go-dt/dtx through replace directives pointing at sibling checkouts, so it builds only on this machine. It has no CI or Release workflow, and tags in go-pkgs are created by a repo's generated Release workflow, never by hand. main has one uncommitted go.mod change raising go-dt. The GitHub repo exists with a single LICENSE-only commit that shares no history with the local commits. Decided: require go-diffutils v0.1.0, its latest tag and identical to its current main; a later go-diffutils tag never forces go-gitutil to re-tag, so there is no reason to wait for one. Also: .gitignore must list go.work and go.work.sum, since Endless writes a go.work into each Go task worktree.
